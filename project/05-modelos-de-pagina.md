# Modelos de página

| Modelo | Composição | Rodapé | Camada |
|---|---|---|---|
| Capa | nome do curso, ciclo, título do relatório | não | núcleo |
| Sumário | título centrado + lista com links + índice de disciplinas por ano/período | não | núcleo |
| Resumo Executivo | título centrado + prosa + box de adesão + chips de domínio + prosa + declaração/nota + assinaturas | sim | núcleo |
| Contracapa de seção | C17 | não | núcleo |
| Percepção geral do curso | cabeçalho + escalas + box de infraestrutura + metodologias + temas + notas | sim | núcleo (conteúdo do perfil) |
| Painel do ano/período | cabeçalho + escalas + itens das disciplinas + chips + cards | sim | núcleo |
| Folha da disciplina | cabeçalho + itens + metodologias + cards + temas | sim | núcleo |
| Panorama dos comentários | cabeçalho compacto + tabela de disciplinas e contagens | sim | núcleo |
| Íntegra | cabeçalho + composição + por domínio: faixa, comentários, sensíveis | sim | núcleo |
| Contracapa por disciplina | C18 | não | núcleo |
| Série comparativa | cabeçalho (variante) + escalas por edição + notas | sim | perfil |
| Página de programa | cabeçalho de programa + barras na paleta do programa | sim | perfil (Medicina: mentoria) |
| Capa final | arte fixa, sem alteração | não | D12 |

**Ordem das seções.** O núcleo fixa o começo (Capa, Sumário, Resumo Executivo) e o fim (Comentários, Capa final). As seções intermediárias vêm do perfil do curso.
