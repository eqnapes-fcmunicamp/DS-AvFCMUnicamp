Identifica o curso, o ano ou período, a disciplina ou o domínio de um comentário.

## Anatomia

Rótulo curto em Google Sans 700, caixa alta, com `raio-chip`. Curso, ano e código usam `verde-codigo`; disciplina usa `chip-claro` com texto `capa`; domínio usa `capa` com texto `sobre-escuro`.

## Tokens

`verde-codigo`, `chip-claro`, `capa`, `sobre-escuro`, `raio-chip`.

## Variações

Quatro tipos: curso, ano ou período, disciplina, domínio.

## O que não fazer

Não crie chip de outra cor para distinguir o curso (D11). Não passe de duas palavras.

## O que o consumidor fornece

Texto do chip e o tipo.

## Exemplo de referência

Pendente. Nenhum exemplo aprovado registrado (ver Exemplos de referência).

## Pontos a confirmar

A preview mostra o código «AB000» como exemplo; o formato do código vem do instrumento do curso.
