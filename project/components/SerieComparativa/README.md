Mostra um mesmo percentual ao longo das edições da avaliação, na série comparativa.

## Anatomia

Pontos de `verde-barra` com filete `papel`, valor inteiro acima de cada ponto, ciclo no formato `AAAA.S` abaixo, grade em 0%, 50% e 100%. Eixo de 0% a 100%. A linha entre os pontos só existe quando as edições estão em intervalos iguais.

## Tokens

`verde-barra`, `papel`, `trilho-barra`, `texto`, `texto-2`, `numero-barra`.

## Variações

Com linha (intervalos iguais) e sem linha (intervalos desiguais). Mais de uma série exige cor por série, que o sistema ainda não define (D18).

## O que não fazer

Não desenhe linha de tendência em intervalos desiguais. Não descreva a série como progressão de uma turma: cada edição avalia turmas diferentes. Não corte o eixo. Não escreva o ciclo fora de `AAAA.S`.

## O que o consumidor fornece

Ciclos no formato AAAA.S, percentuais e a base de cada ponto (nota C20).

## Exemplo de referência

Pendente. Nenhum exemplo aprovado registrado (ver Exemplos de referência).

## Pontos a confirmar

Série única apenas; paleta para várias séries e o cabeçalho comparativo (V6) seguem em aberto (D18).
