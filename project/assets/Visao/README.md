# Visão

Imagens que resumem o sistema. `mapa-do-sistema.svg` mostra, numa página, os quatro blocos (tokens, núcleo e perfis, componentes, divulgação) e o que há fora deles. Usa as cores `petroleo`, `capa`, `verde-barra`, `noturno`, `adesao`, `anel` e `fundo-box` do sistema, gravadas no arquivo (SVG não lê tokens): se um token mudar, refaça a imagem. Fonte do texto: Arial no SVG, porque imagem carregada por `<img>` não usa as fontes do sistema.
